Sources

Two classes of source are used. OLBG supplies the fixture universe, markets, prices and tip counts. Official competition sources supply form, standings and results where a usable feed exists. Nothing else is used.

4. Reproduction

scripts/fetch-raw.yml (GitHub Action) → data/raw/*.html
scripts/parse_olbg.py → data/fixtures.json
scripts/parse_events.py → data/markets.json
scripts/extract_official.py → data/official_facts.json
scripts/pricing.py → data/lines.json
scripts/select_picks.py → data/picks.json
scripts/build_site.py → this site

The crawler runs on a GitHub runner (manual or daily at 06:17 UTC); the parsing, pricing, selection and build steps run locally or in the same runner and are deterministic given the snapshots.
