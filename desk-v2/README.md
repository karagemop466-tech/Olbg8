# Archived root desk (desk-v2)

This is a byte-for-byte archive of the desk that occupied the repository root at
`main` commit `06c88d4` (the session-`438bbe65` build: 190 events, 223 markets,
257 priced selections, 63 picks). It was archived, not deleted, when the
`c2f58873` pipeline build took over the root on 2026-10-27.

Its own files still resolve inside this folder: `index.html`, the fifteen files
in `sports/`, `assets/`, and the `data/desk-*.json` payloads it renders.

The current root desk is at `/` and is generated by `pipeline/site.py` from
`data/desk.json`.
